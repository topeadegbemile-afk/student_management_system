# School Management System

A Node.js and MongoDB-based school management system designed to manage students, teachers, parents, classes, subjects, sessions, and academic results.

## Features

* Student management
* Teacher management
* Parent management
* Class and subject management
* Student results management
* User authentication and role-based access
* MongoDB database integration

## Technologies

* Node.js
* Express.js
* MongoDB
* Mongoose
* JavaScript
* postgres
